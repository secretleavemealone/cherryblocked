# CherryBlocked

A responsive cherry-blossom themed dashboard starter with frosted-glass buttons.

## Run locally
Open `index.html` in a browser, or serve this folder with any static web server.

## Deploy to Vercel
Import this repository into Vercel. No build command is needed; set the output directory to `.` if prompted.

## Included
- Responsive home dashboard and glass UI
- Search/filter launchpad tiles
- Modal navigation for Games, AI Studio, Chat, Developer Tools, and Settings
- Browser-local settings
- Local JSON formatter, Base64 encoder, URL encoder, and timestamp utility

## Not connected yet
Real game catalog/embeds, AI responses, user accounts, cross-user live chat, cloud profiles, and saved favorites require service configuration and a secure backend. Do not place API keys in browser JavaScript.

## Background
The current CSS uses a built-in blossom-inspired gradient. Add your image as `assets/cherry-garden.png` and update the `.backdrop` background rule if you want to use the original garden image.
